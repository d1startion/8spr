# Post Service (Golang)

Backend-сервис для управления и отслеживания посылок.

---

## 🚀 Возможности

* CRUD операции для посылок
* Управление статусами (создание, обновление, завершение)
* Базовые бизнес-правила для изменения статусов
* Unit-тесты для бизнес-логики

---

## 🧱 Архитектура

Проект построен с разделением ответственности:

* **service** — бизнес-логика и правила работы со статусами
* **repository** — взаимодействие с базой данных

---

## ⚙️ Технологии

* Go
* SQLite
* database/sql
* testify

---
